Use supported Gemini 3.6 Flash

## Goal
Select the right Gemini Flash model after the retirement of `google/gemini-2.5-flash`.

## Decision
`google/gemini-3.7-flash` is not currently in the Lovable AI Gateway model catalog, so the request will be rejected with a 400 if used. We will stay on the latest supported Gemini Flash model: `google/gemini-3.6-flash`.

## Current State
Both AI-powered edge functions are already set to `google/gemini-3.6-flash`:
- `supabase/functions/generate-company-briefing/index.ts` (line 787)
- `supabase/functions/generate-contact-enrichment/index.ts` (line 386)

## Action Plan
1. Confirm the model string in both edge functions is exactly `google/gemini-3.6-flash`.
2. Deploy the edge functions.
3. Run a smoke test against each function to verify the gateway responds with 200 and valid output.

## Notes
- No request-body changes are needed; `google/gemini-3.6-flash` supports the same chat-completions, tool-calling, and JSON schema constraints already in use.
- If/when `google/gemini-3.7-flash` is added to the gateway catalog, we can switch with a simple two-line model-id update and re-deploy.
